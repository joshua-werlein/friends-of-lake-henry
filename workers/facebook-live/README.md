# Facebook raffle discovery

Current implementation and production verification: [post-rotation report](../../docs/facebook-automation-production-2026-11-03.md).

The Live Worker discovers candidates through Page published_posts and verifies individual video metadata. It does not call the restricted Live Video API or require a hashtag. Only positive Live status, or a same-video replay backed by a stored genuine Live observation, qualifies. Ambiguous VOD stays pending for manual confirmation.

Polling and signed event forwarding share the existing singleton Durable Object. Automatic replacement is limited to the confirmed November 2026 drawing window (17:50–18:30 Central); replay display may continue afterward. Preserve the existing account, DO migration, namespace, KV and encrypted secrets.

Automatic selection additionally requires the matching reviewed schema-5 policy receipt and independent admin enablement. The administrator's Test discovery action is read-only and cannot publish a video. No production receipt is generated by tests or deployment.

The separate winner-photo Worker uses its own encrypted Page token, D1 queue and Workers AI. A private Page-read binding is only a fallback when its own token is absent. Its signature-verified webhook receiver can forward video hints without coupling extraction to video discovery success.
